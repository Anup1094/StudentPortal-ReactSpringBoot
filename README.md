# StudentPortal-ReactSpringBoot

A Full Stack Student Management Portal built with React and Spring Boot.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Spring Boot (REST APIs)
- **Database:** MySQL

## Features
- Add Student
- View All Students
- Edit/Update Student
- Delete Student
- Full CRUD Operations

## How to Run

### Backend
1. Import `studentmanagement` in IntelliJ
2. Configure MySQL in `application.properties`
3. Run `StudentmanagementApplication.java`

### Frontend
1. Open `student-portal` in VS Code
2. Run `npm install`
3. Run `npm start`
